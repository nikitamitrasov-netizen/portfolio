# Сайт-визитка учителя

Статический сайт: открывается двойным щелчком по `index.html`, интернет и установка программ не нужны.

## Страницы

```
index.html          главная: приветствие, три плитки, недавние фото, контакты
about.html          обо мне, образование и документы о повышении квалификации
materials.html      методические материалы, скачивание, цифровые проекты
class.html          жизнь класса: 25 фотографий с фильтром «поездки / мероприятия»
achievements.html   достижения: 13 наград класса, награды учителя и учеников
```

Меню в шапке общее для всех страниц, текущая страница подсвечивается. Внизу справа появляется кнопка «наверх».

## Папки

```
css/style.css       оформление
js/main.js          меню, фильтр фото, просмотр на весь экран, кнопка «показать все»
assets/photos/      фотографии: portrait.jpg, trip-1…9.jpg, event-1…16.jpg,
                    ach-1…6.jpg, class-1…13.jpg, kurs-1…6.jpg
assets/img/         заглушки, если фото ещё нет
files/karty/        архивы технологических карт по классам
files/listy/        рабочие листы по классам
```

## Как добавить фотографию

1. Положите файл в `assets/photos/` с именем `trip-10.jpg` или `event-17.jpg`.
2. В `class.html` скопируйте блок `<figure class="photo" …>` и поменяйте номер и подпись.

Фильтр работает по атрибуту `data-cat`: `trip` это поездки, `event` это мероприятия.

## Как добавить награду класса

1. Положите снимок в `assets/photos/` с именем `class-14.jpg` (или обработайте всю папку скриптом `build_class_awards.py` в корне рабочей папки).
2. В `achievements.html` найдите блок `id="class-awards-grid"` и скопируйте любую карточку `<figure class="doc award" …>`.
3. Поменяйте номер фотографии, подпись и `data-cat`: `5g`, `6d`, `7d` или `7a`. От этого зависит фильтр по классу.
4. Если класс новый, добавьте кнопку в блок `.tabs` с таким же `data-filter`.

В карточках наград фотография показывается целиком (`object-fit: contain`), поэтому обрезать документ не нужно. Клик открывает снимок на весь экран.

## Как поменять тексты

Все страницы это обычный HTML, открывается блокнотом. Меняются только тексты внутри тегов, структуру трогать не нужно.

## Как обновить материалы

Архивы в `files/karty` и файлы в `files/listy` собраны из папок `Технологические_карты_*` и `Рабочие_листы`. После правок в docx их нужно пересобрать заново и заменить файлы.

## Как выложить в интернет

1. **GitHub Pages.** Создать репозиторий, загрузить папку, включить Pages в настройках.
2. **Хостинг** (TimeWeb, Beget, reg.ru). Папку залить по FTP в `public_html`.
3. **Netlify.** Перетащить папку на сайт netlify.com.

Вес сайта около 20 МБ, основное это фотографии и архивы с материалами. Если нужно легче, уменьшите фото до 1100 пикселей или выложите архивы отдельным файловым хранилищем.
